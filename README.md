# WhisperKey releases

Signed builds of WhisperKey, a personal hold-to-talk dictation app for macOS 14+. Source is private; this repo holds release files only.

**Install:** download `WhisperKey.dmg` from the latest release, open it and drag WhisperKey to Applications. On first open, macOS blocks it because it is not notarised: use System Settings → Privacy & Security → **Open Anyway**.

**Update:** WhisperKey menu → **Check for updates…**. An update installs only if it is signed with the same certificate as the app you are running.
